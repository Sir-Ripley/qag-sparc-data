Schema

{
  "galaxies": {
    "<NAME>": {
      "p": [v_inf_kms, r_aff_kpc],
      "c": [qag_chi2_red, mond_chi2_red, newton_chi2_red, qag_rms_kms],
      "f": flags (1 = LOW_DOF, 2 = r_aff pinned),
      "pts": [[r_kpc, v_obs, err, v_baryon], …]
    }
  }
}

v_baryon = √(0.5·(vdisk² + vbulge²) + vgas²), Υ★ = 0.5. Curves: Newton v = vbar; QAG v² = vbar² + v∞²(1−e−r/raff); MOND via the simple interpolating function, a₀ = 1.2×10⁻¹⁰ m/s².

Provenance

Source: SPARC database (Lelli, McGaugh & Schombert 2016). Ingestion: ingest_sparc.py v1.0.0 with per-file SHA1 manifest. Fits: sweep_v3.py per-galaxy least squares. Full-fidelity source (all points, full precision) + build script: github.com/Sir-Ripley/qag-sparc-data.
